🎯 Cara Instan Dapat Badge Pull Shark

1
Fork Repository SharkyBed

Buka repo ini di GitHub lalu klik Fork.

2
Edit File Langsung di Web GitHub (Paling Cepat!)

Buka file SHARKS.md atau data/sharks.json di repo hasil fork kamu, klik icon pensil ✏️ (Edit), lalu tambahkan baris nama kamu.

3
Atau Lewat Git Terminal (Lokal) 
git clone https://github.com/<USERNAME-KAMU>/pull-shark-badge.git
cd pull-shark-badge
git checkout -b hiu-baru-<namamu>
# edit data/sharks.json atau SHARKS.md
git add .
git commit -m "feat: add shark contributor <namamu> 🦈"
git push origin hiu-baru-<namamu>
4
Buka Pull Request & Tunggu Auto-Merge

Klik tombol "Compare & pull request" di GitHub. Bot SharkyBed akan otomatis me-merge PR kamu dalam 10-30 detik!
